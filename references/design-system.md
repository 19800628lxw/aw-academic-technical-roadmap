# 学术技术路线图美学设计系统 v2.0

本设计系统定义"学术简约风"的量化规范。生成器 `scripts/gen_roadmap.py` 已内置全部参数；人工在 drawio 微调时对照执行。

## 1. 设计原则（四优先）

1. **留白优先**：画布元素占比 ≤ 60%，阶段框之间保持呼吸感
2. **黑白灰优先**：默认纯黑白灰；仅当确需区分模块属性时，引入低饱和强调色（见 §5）
3. **对齐优先**：所有框体严格网格对齐，禁止肉眼估距
4. **一致性优先**：同级元素同尺寸、同字号、同线型

## 2. 版面参数（A4）

| 范式 | 页面方向 | pageWidth×pageHeight | 主内容列 |
|---|---|---|---|
| 纵向递进五段式 | 竖版 | 827×1169 | x=60, w=560；右留 147px 给方法栏 |
| 三栏并行式 | 横版 | 1169×827 | 三栏各 w=350，间距 20 |
| 逻辑闭环式 | 竖版 | 827×1169 | 圆环布局，中心(413,580)，半径 240 |

页边距 ≥ 40px；标题距页顶 40px。

## 3. 字号层级（三级封顶）

| 层级 | 字号 | 字重 | 用途 |
|---|---|---|---|
| L1 | 15 | 粗体 | 图题/课题名称、结论框 |
| L2 | 13 | 粗体 | 阶段标题、栏目标题 |
| L3 | 11 | 常规 | 子内容框 |

禁止第四级字号；框内文字超过 2 行时先精简文字再缩字号。

## 4. 几何规范

- 子内容框：高 60px；单行宽 = `min(150, (容器宽-2×边距8-(n-1)×15)/n)`，一行最多 4 个，超出自动换行（行距 12px）
- 阶段容器：头区 45px + 内容行 + 底部留白 20px，高度随行数自适应
- 阶段间距（纵向箭头区）：40px；栏间距（横向箭头区）：20px
- 闭环式节点：180×80px，等角分布于圆环，首节点置于正上方（-90°）
- 标题框 360×50，结论框 360×50，水平居中于主内容列

## 5. 色彩令牌

| 令牌 | 值 | 用途 |
|---|---|---|
| ink | `#000000` | 图题边框、主逻辑箭头 |
| body | `#333333` | 子内容框边框 |
| stage | `#666666` | 阶段虚线框、栏目标题、方法栏边框 |
| mute | `#999999` | 方法栏关联虚线、反馈迭代箭头 |
| wash | `#F5F5F5` | 方法栏/图例底色 |
| paper | `#FFFFFF` | 一切框体底色 |

可选低饱和强调色（整图 ≤ 2 种，仅用于"核心创新/关键产出"类模块）：
`#4472C4`（蓝）/ `#C55A11`（橙），配 `fillColor` 使用，禁止与黑白灰以外的颜色混用。

## 6. 线型规范

| 类型 | 样式 | 语义 |
|---|---|---|
| 实线箭头 | orthogonal, rounded=0, ink | 主逻辑流（阶段串联、栏目递进） |
| 虚线框 | dashed=1, stage | 阶段/栏目的边界（弱化边界、强化内容） |
| 虚线箭头 | dashed=1, mute | 辅助关联（方法↔阶段、反馈回路） |
| 闭环弧线 | curved=1, ink | 闭环式节点间流转；末段虚线表迭代 |

## 7. 人工校准清单（drawio 内执行）

1. 全选 → 右键"编辑样式"核对颜色是否落在色彩令牌内
2. 框选每列/每行 → "排列 → 同等宽度/分布" 强制对齐
3. 文字溢出的框：双击进文字层删冗词，或右键"编辑 → 自动调整大小"
4. 箭头未吸附：拖拽端点至框体蓝点；删除交叉箭头改为绕行
5. 导出前缩放 25% 整图审阅：层次是否一眼可辨、有无视觉噪点
